# Fortnite Token Odds

A free, single-file, responsive, interactive visualization of the Fortnite Pirate Shop Access token's published drop odds.

## Run

Open `index.html` in a modern web browser. Everything interactive works locally and requires no backend. Google Fonts is an optional enhancement; fallback fonts are included.

## Interactions

- A literal 550 × 250 pixel map: exactly 137,500 outcomes with one winning pixel.
- Probability calculator and curve with 1× normal and 1.5× Treasure Hour rates.
- Randomized chest-opening simulation, using a geometric waiting-time model.
- Three-hour playtime reality check with adjustable chests per hour.

The probabilities represent independent chest trials with the selected constant rate. The simulator stops after one drop because Epic states non-Gizmo treasures cannot be obtained twice.

## Published odds

- Normal: 1 / 137,500 per eligible chest.
- Standard Treasure Hour: 1.5× normal probability (higher multipliers may be announced for specific events).

Source: [Epic Games Support — Fortnite treasure drop rates](https://www.epicgames.com/help/c-34254770/c-33726977/what-are-the-drop-rates-of-treasure-in-chests-in-fortnite-battle-royale-s-pirate-treasure-event-a14361627)
